# Month 1 — Host Investigation

## Structure
- `case/`: Case summary and investigation scope.
- `evidence-notes/`: Analysis notes and evidence map.
- `timeline/`: Investigation timeline files.
- `scripts/`: Automated detection utility.
- `detections/`: Detection rules.
- `tests/`: Test plan, test results, and test code.
- `final-report/`: Final investigation report.

## Current Assessment
No confirmed host compromise was established from the available evidence.

## Limitations
The investigation primarily used point-in-time host telemetry. The findings
do not prove that the host is completely clean.
