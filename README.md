# Digital Forensics & Secure Host Engineering

A hands-on cybersecurity portfolio documenting practical work in digital forensics, Linux host investigation, security analysis, and secure host engineering.

This repository brings together investigation reports, technical documentation, scripts, detection work, and practical security labs.

## Repository Overview

### 1. Month 1 — Host Investigation

A practical host-investigation project covering:

- Investigation documentation and findings.
- Evidence notes and analysis.
- Timeline development.
- Security scripts and detection work.
- Testing and final reporting.

### 2. Secure Host Engineering

A collection of practical labs focused on Linux system security, host inspection, security configuration, and automation.

The directory contains ten daily lab folders, with supporting scripts and documentation.

## Methodology

The work emphasizes:

- Structured and reproducible investigation.
- Evidence integrity and verification.
- Clear documentation of observations.
- Separation of confirmed findings from assumptions.
- Transparent reporting of limitations.
